# Daily Task Tracker

Одностраничный трекер ежедневных задач по ТЗ (`info/TZ.txt`). React + Vite, хранение в `localStorage`, без сервера и регистрации. Дополнительно: словарь проектов, дедлайн у задачи и выгрузка в Excel.

## Запуск

```bash
npm install
npm run dev      # разработка: http://localhost:5173
npm run build    # продакшен-сборка в dist/
npm run preview  # предпросмотр сборки
```

## Проверка

```bash
npm test         # юнит-тесты логики (node --test)
npm run smoke    # сборка + сценарии ТЗ в headless Chrome + скриншоты в screenshots/
```

`npm run smoke` проходит 14 тестовых сценариев из ТЗ и пишет скриншоты:
`01-first-run.png`, `02-mobile.png`, `03-final-desktop.png`, `04-all-done.png`,
`05-projects-export.png`.

## Структура

```
src/
  App.jsx                 # состояние приложения, обработчики, layout
  hooks/useLocalStorage.js# чтение/запись + обработка ошибок хранилища
  utils/tasks.js          # модель данных (проект, дедлайн), фильтры, статистика
  utils/projects.js       # словарь проектов
  utils/export.js         # выгрузка задач в .xlsx
  utils/date.js           # форматирование дат
  components/
    Header.jsx            # шапка: название, дата, слоган
    StatsCards.jsx        # 4 карточки статистики + progress bar
    AddTaskForm.jsx       # форма добавления: название, описание, проект, дедлайн
    ProjectsBlock.jsx     # словарь проектов: добавление/удаление
    ProjectSelect.jsx     # выпадающий выбор проекта
    ExportButton.jsx      # выгрузка всех задач в Excel
    Filters.jsx           # фильтры Все / Активные / Выполненные
    TaskList.jsx          # список, счётчик, пустые состояния
    TaskItem.jsx          # карточка задачи: чекбокс, проект, дедлайн, редактирование
    EmptyState.jsx        # сообщение пустого списка
  styles.css              # дизайн: светлый минимализм, адаптив
```

## Проверено

- добавление (название обязательно, пустая задача не добавляется);
- выполнение/возврат в активные, пересчёт статистики и progress bar;
- редактирование и удаление с подтверждением;
- фильтры, пустое состояние, сообщение «Все задачи выполнены»;
- сохранение после перезагрузки страницы;
- адаптив на 375 px без горизонтального скролла;
- словарь проектов: добавление, защита от пустых значений и дубликатов, удаление с подтверждением;
- выбор проекта и дедлайна в форме и при редактировании, бейджи на карточке, метка просрочки;
- выгрузка всех задач в `.xlsx` (колонки: название, описание, проект, дедлайн, статус, создано);
- консоль браузера без ошибок.
